# JARVIS Cognitive Care Platform

An AI-based cognitive gaming and memory-assistance platform for elderly dementia patients,
featuring a JARVIS-style voice assistant, memory games, reminders, and a family photo quiz.

## Setup

```bash
npm install
npm run dev
```

Then open **http://localhost:5173**

## Notes
- Voice features (speak/listen) use the Web Speech API — use **Chrome** or **Edge**, and allow microphone access when prompted.
- Reminder data is saved in your browser's localStorage.
- Build for production: `npm run build`, preview it: `npm run preview`.
